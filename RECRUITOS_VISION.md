# RecruitOS Vision

## The Mission
To build a **Recruitment Operating System** that feels like a native Apple application: fast, opinionated, beautiful, and utterly devoid of clutter.

## Core Philosophies

### 1. Speed is a Feature
If a Field BDA takes 15 seconds to enter a lead instead of 5, the app has failed. Every interaction must be instant.

### 2. Linear Pipeline
Recruitment is a funnel. The software should visually represent this funnel at all times.
Lead → Interview Scheduled → Selected → Recharge → Joined.
No side quests. No confusing states.

### 3. Purpose-Driven Screens
- **The Dashboard:** "What do I need to do right now?"
- **The Kanban:** "Where is everyone?"
- **The Timeline:** "What happened with this person?"
- **The Marketing View:** "Is my money working?"

### 4. Zero Bloat
No payroll, no attendance, no AI chatbots, no document parsing. Just pure, unadulterated candidate pipeline management and marketing ROI tracking.

### 5. Aesthetics Matter
- **Minimal:** Remove borders, use whitespace.
- **Modern:** Subtle micro-animations, glassmorphism where appropriate, dark mode by default.
- **Intentional:** Buttons should be obvious. Information hierarchy must be perfect.

This is not a CRM. This is RecruitOS.
